# L.P.S Liyanage — Portfolio

A modern personal portfolio website built to showcase my projects, skills, and background as a software developer and IT undergraduate at SLIIT.

## Live Demo

🔗 [future-portfolio-pqs1.vercel.app](https://future-portfolio-pqs1.vercel.app)

## Built With

- HTML5
- CSS3 (custom — no frameworks)
- Vanilla JavaScript
- Font Awesome 6
- Google Fonts (Inter)

## Features

- Fullscreen hero section with video background
- Responsive design (mobile, tablet, desktop)
- Glassmorphism card UI
- Smooth scroll & active nav highlighting
- Projects section with live demo & GitHub links
- Skills bento grid
- Contact section

## Sections

| Section | Description |
|---|---|
| Hero | Intro with availability badge and stats |
| Projects | Featured work with links |
| Skills | Tech stack organized by category |
| About | Background and fun facts |
| Contact | LinkedIn, Email, GitHub, Phone |
